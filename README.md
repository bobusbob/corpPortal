# Корпоративный портал

Учебный портал: регистрация и личный кабинет через Supabase, дальше — вкладки с выполненными заданиями курсов.

## Публикация

Адрес сайта: https://bobusbob.github.io/corpPortal/

При отправке ветки `main` на GitHub Actions собирает проект и публикует папку `dist` на GitHub Pages. Отдельный хостинг для этого не нужен. Публичный ключ Supabase для сборки лежит в `.env.production`.

## Запуск

```bash
npm install
npm run dev
```

Ключи для этого компьютера лежат в `.env.local` и в Git не попадают. На другой машине скопируйте `.env.example` в `.env.local` и подставьте URL и publishable key проекта `corpPortalDB`.

## Регистрация

Учётная запись создаётся в Supabase Auth: почта и пароль. Профиль пишется в таблицу `public.profiles`:

- `email`
- `username` — имя пользователя, уникальное без учёта регистра
- `full_name` — отображаемое имя
- `avatar_url` — пока пустое, пригодится позже
- `created_at`, `updated_at`

Пароль в `profiles` не хранится.

Вход выполняется по имени пользователя и паролю. Почта по-прежнему хранится в учётной записи.

Подтверждение почты сейчас выключено: после регистрации сразу открывается кабинет. Включить его снова можно в Supabase: Authentication → Sign In / Providers → User Signups → Confirm email.

## Новый раздел курса

Добавьте компонент в `src/sections` и одну запись в `src/sections/registry.ts`. Вкладка появится в кабинете.
